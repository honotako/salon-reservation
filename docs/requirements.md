# 要件・機能一覧

## 目的

個人経営の美容院では、LINE、電話、SNS など複数の経路から予約が入り、管理が大変になっている。
このシステムでは、すべての予約を一か所にまとめて管理できるようにし、美容師の業務を効率化する。

## 想定するお店

- 美容師が3人ほどの個人経営の美容院
- 予約枠は美容師ごとに1つ（同じ時間でも、別の美容師なら予約できる）

## 利用者

| 利用者 | 主な使い方 |
| --- | --- |
| お客さん | 空いている日時を見て予約する。自分の予約を変更・キャンセルする |
| 美容師 | 予約をカレンダーで確認する。電話や LINE で受けた予約を登録する |

## 機能一覧

### フェーズ1（最初に作る）

**美容師側**

- ログイン
- 予約をカレンダーで表示（日ごとの予約件数がわかる）
- 予約を手で登録（電話、LINE、SNS などで受けた予約用）
  - 入力項目：お客さんの名前、日時、メニュー、担当の美容師、予約経路
- お店の設定
  - 営業時間（毎日同じ。例：10:00〜18:00）
  - 予約の時間の刻み（お店で1つ。例：30分）
  - 毎週の定休日（例：水曜日）
  - 臨時休業（年末年始、急な用事など）

**お客さん側**

- 空いている日時を見て予約する
  - 入力項目：メニュー、指名する美容師（指名は必須）、日時、お客さんの名前、メールアドレス
  - 埋まっている時間はグレーで表示し、選べないようにする
  - 予約を確定する前に、内容を確認できるようにする

### フェーズ2（あとで追加する）

**お客さん側**

- 会員登録、ログイン
- 自分の予約の一覧表示
- 予約の変更・キャンセル（予約日の3日前まで）

### 今後の検討

- 「指名なし」で予約し、空いている美容師に自動で割り当てる
- 美容師個人の休みの設定
- 曜日ごとに違う営業時間

## システムとして守るルール

- 同じ美容師の同じ時間に、予約が2件入らないようにする
- 同時に予約が入った場合は、先に確定した予約を優先する
- 予約の変更・キャンセルは、予約日の3日前まで
- 営業時間外、定休日、臨時休業の日は予約できないようにする
